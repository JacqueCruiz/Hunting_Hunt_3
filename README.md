# Hunting Hunt 3

A mobile-first, low-poly hunting adventure prototype. The current branch contains the initial Vite + React + TypeScript vertical slice for aiming, anatomy targeting, tracking, and processing.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite. The prototype is playable with a mouse, keyboard, or touch-friendly buttons.

## Prototype flow

1. Select an anatomy target.
2. Aim down sights to activate the breathing reticle.
3. Fire to resolve the shot.
4. Follow the trail after a non-clean hit.
5. Process the animal at the home table.

See `src/` for the planned game architecture: hunting, weapons, processing, data, hooks, UI, and styles.
